# Ozon Copy Data

![Ozon Copy Data](https://github.com/user-attachments/assets/3e3e3e91-4f0b-4662-898b-e023bb09cb8b)

Копирует данные с карточки товара на [ozon.ru](https://ozon.ru/product/) — название, артикул, цену, состав, характеристики и другие поля. Работает и в каталоге/поиске: кнопки прямо на плитках товаров, массовое добавление в буфер и автопрокрутка для сбора всех товаров. Поддерживает накопительный буфер с выбором полей, предпросмотром и скачиванием в `.txt`.
