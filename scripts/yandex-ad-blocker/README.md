# Yandex Ad Blocker

![Yandex Ad Blocker](https://github.com/user-attachments/assets/b755e95c-7c8a-4fe8-9d04-4b558a66111c)

Скрывает рекламу в выдаче Яндекса ([ya.ru](https://ya.ru/), yandex.by / .ru / .com / .kz): рекламные сниппеты и галереи, результаты с пометками «Реклама» и «Промо», окно «Часть сайтов недоступна — скачайте Яндекс Браузер» (заодно возвращается прокрутка страницы) и баннеры «Установите Яндекс Браузер». Рекламные блоки находятся по видимой метке, а не по хешированным классам, поэтому скрипт переживает смену вёрстки; новые результаты, подгружаемые динамически, обрабатываются автоматически.
