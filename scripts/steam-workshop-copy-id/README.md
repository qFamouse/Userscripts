# Steam Workshop Copy ID

Копирует ID предметов Мастерской Steam — для одного мода или сразу для многих. На каждой карточке появляется чип с ID (клик — скопировать), а в углу превью — чекбокс для выбора (Shift+клик выбирает диапазон). Внизу страницы плавающая панель: «Все на странице», «Сбросить», выбор разделителя (строки / запятая / пробел) и кнопка «Копировать ID». Выбор сохраняется между страницами и вкладками. На странице самого предмета в панели есть ID текущего мода и кнопка «В список».
