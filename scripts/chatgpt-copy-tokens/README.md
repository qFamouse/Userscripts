# ChatGPT Copy Tokens

Две кнопки в стиле ChatGPT в правом нижнем углу [chatgpt.com](https://chatgpt.com/) — копируют `accessToken` и `refreshToken` текущей сессии в буфер обмена. В веб-версии отдельного refresh-токена нет, поэтому его роль играет `sessionToken`. Поддерживает светлую и тёмную темы сайта.
