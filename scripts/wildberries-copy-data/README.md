# Wildberries Copy Data

Копирует данные с карточки товара на [wildberries.by](https://www.wildberries.by/) (а также .ru / .kz / .kg / .am / .uz) — название, артикул, бренд, продавца, цену, рейтинг, описание, состав, характеристики и другие поля. Работает и в каталоге/поиске: кнопки прямо на плитках товаров, массовое добавление в буфер и автопрокрутка для сбора всех товаров. Поддерживает накопительный буфер с выбором полей, предпросмотром и скачиванием в `.txt`.
