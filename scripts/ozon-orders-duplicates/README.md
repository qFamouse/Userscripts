# Ozon Orders Duplicates

На странице «Заказы» [ozon.ru](https://www.ozon.ru/) / [ozon.by](https://www.ozon.by/) объединяет одинаковые товары в карточки «по товарам» и сравнивает цены разных заказов. Показывает текущую цену товара на сайте, подсказывает, от каких заказов стоит отказаться при получении (дороже самой выгодной покупки) и что выгодно перезаказать (сейчас дешевле). Для каждой позиции есть ссылка на заказ и на товар — открываются в новой вкладке, в том числе средней кнопкой мыши. Режим «Как на Ozon» возвращает оригинальный вид списка. Данные заказов и цены кэшируются; кэш можно сбросить из меню менеджера скриптов.
