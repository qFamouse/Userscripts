# Steam Workshop Multilang Editor

Встроенный редактор названия и описания мода в Мастерской Steam сразу для всех языков — прямо на странице редактирования текста предмета (`sharedfiles/itemedittext`). Описание разбивается на секции, а числа, версии, ссылки, названия и флаги можно поправить разом во всех языках. Перед сохранением показывается diff изменений, сохранение выполняется пакетно для всех затронутых языков, а прежние тексты попадают в историю сохранений (отдельно для каждого мода).

Интерфейс скрипта автоматически переключается на язык Steam: English, Русский, Українська, 简体中文, 繁體中文, 日本語, 한국어, Deutsch, Français, Español, Português (Brasil), Polski, Türkçe. Для остальных языков используется английский.
