# Maktun Export

Кнопка «Экспорт в Excel» на странице коллекции [web.maktun.com](https://web.maktun.com/) — выгружает все монеты коллекции в `.xlsx`: ваши фото аверса/реверса и дополнительные фото прямо в ячейках, название, страна, KM-код, годы выпуска, номинал, материал, вес, диаметр и другие характеристики из каталога. Кнопка и панель прогресса встроены в дизайн сайта, экспорт можно отменить, в таблице включены фильтры по колонкам.
