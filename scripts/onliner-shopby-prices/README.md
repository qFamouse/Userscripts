# Onliner + Shop.by Prices

![Onliner + Shop.by Prices](https://github.com/user-attachments/assets/19198861-bd05-4911-b8d6-2fe236224851)

Автоматически показывает цены с [shop.by](https://shop.by) прямо в карточках товаров на [onliner.by](https://catalog.onliner.by/) — с кешированием результатов на 6 часов.
