# Habr Promo Cleaner

<!-- ![Habr Promo Cleaner](https://github.com/user-attachments/assets/...) -->

Убирает рекламу и кросс-промо блоки на [promo.habr.com](https://promo.habr.com) (чужие офферы среди промокодов) и красит кнопку «Показать промокод» в зелёный цвет. Работает и с динамически подгружаемыми промокодами.

[![Install with Tampermonkey](https://img.shields.io/badge/Tampermonkey-Install-brightgreen?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/qFamouse/Userscripts/refs/heads/master/scripts/habr-promo-cleaner/habr-promo-cleaner.user.js)
